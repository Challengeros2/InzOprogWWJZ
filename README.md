# Wirgo

Prosty, przeglądarkowy system zarządzania parkiem rozrywki.

## Funkcjonalności

- Zarządzanie biletami i opaskami
- Obsługa zamówień gastronomicznych
- Zarządzanie statusem atrakcji
- Harmonogramy pracowników
- Symulacja weryfikacji wejścia

## Technologie

- HTML
- CSS
- JavaScript
